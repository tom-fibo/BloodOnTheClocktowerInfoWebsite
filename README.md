This is a GitHub Pages website (<https://tom-fibo.github.io/BloodOnTheClocktowerInfoWebsite/>) designed for playing in-person Blood on the Clocktower. It allows the Storyteller to send night information to each player simultaneously (rather than one at a time) using their individual phones. However, it fails at scale (individual devices do not all stay connected), and I have discovered alternatives more recently (e.g. <https://botc.games>), so it is discontinued.

All files here were vibecoded (so that I could practice using AI agents in coding), with only minor editing by hand.
